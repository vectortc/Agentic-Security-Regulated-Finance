What the five invariants mean
C1
Case-bound continuity — every step is appended under the case id, the per-case sequence is gap-free, and the chain is hashed.
C2
Least privilege — a tool runs only under a capability allowed for the agent's role and workflow.
C3
Current-policy grounding — every policy-dependent step cites the approved version effective at that timestamp.
C4
Inference-boundary redaction — only redacted, PII-free structured fields cross to the model.
C5
Decision-evidence reconstruction — the full decision basis is recoverable from the case id alone.
The two readings of Algorithm 5

Two clauses in the manuscript admit more than one reading, so both are implemented. Literal Alg 5 in the control bar switches between them.

line 8
By default Is_Chain_Traversable also requires every step the planner declared to have reached the gate. Read literally, it only requires each TOOL_INVOKED to have a TOOL_COMPLETED.
line 9
By default a violated invariant returns FAILED, per the status-semantics paragraph. Read literally it returns INCOMPLETE, per the pseudocode.

Run the gateway-bypass fault under both. The literal reading certifies the case COMPLETE with the bypass demoted to a finding, which is exactly what Assumption A1 predicts: the ledger never observes the call, so Algorithm 5 may certify a case whose true execution violated an invariant.

About this demo and its data

Every applicant, document, policy and tool response is synthetic, generated from a fixed seed by demo/kyc/generate.py. Distributions follow the shapes the manuscript reports; the values are fabricated. Identifiers use ranges reserved for fiction — SSN area numbers 900–999, which have never been issued; the 555-01XX telephone exchange; the reserved .test domain.

The orchestrator, model and tools are deterministic stand-ins. The ledger, the four gates and the reconstruction are real implementations of Algorithms 1–5 and run in this page. A parity test runs the same engine against the Python core over the same fault matrix, so the two cannot drift. Archived ledger volume is simulated to show that audit cost is O(Ecase), not O(Etotal).
